## Platform Overview

Built a full-stack university event management platform utilizing Node.js, Express, React, and MongoDB. The application acts as a central hub for student registration and administrative approval.

### Technical Achievements

- Engineered robust REST APIs specifically designed to handle multi-step event approval workflows.
- Implemented secure user registration management connected to a MongoDB Atlas cluster.
- Integrated Cloudinary cloud storage to handle optimized image and asset delivery for event campaigns.
